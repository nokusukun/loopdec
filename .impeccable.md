# LoopDec — Design Context

## Design Context

### Users
Personal jam tool. Single user (the maker), loops sourced from YouTube, used in workshop-style sessions — vibing with audio, chopping, looping. Not a product for an audience. Utility over polish.

### Brand Personality
Workmanlike, tactile, deliberately mechanical. Three words: **tactile, instrument, no-nonsense.** Should feel like a piece of gear someone built for themselves, not a product to be sold. Not friendly. Not playful. Just useful.

### Aesthetic Direction
- **Reference**: Hardware sampler — Akai MPC, Elektron Digitakt. Pad grid as the central metaphor. Tally LEDs, address labels on pads (A1, B3), recessed screens, monospaced silkscreen labels, status readouts. The interface is a panel, not a webpage.
- **Anti-references**: iOS / consumer-app aesthetic (no soft cards, no glass, no friendly icons). AI-startup dark UI (no purple-cyan gradients, no neon glow). YouTube red (avoid the red accent that currently leans toward the source-platform's brand).
- **Theme**: Dark. Warm-tinted neutrals (current hue stays). Accent shifts from red-orange to amber/LCD-yellow — the canonical sampler-screen color.
- **Animation**: Functional only. Motion communicates state (transport, focus, LED activation). No decoration.

### Design Principles
1. **Pads, not cards.** Each tile is a numbered position in a fixed grid bank, addressed like sampler pads (A1, A2... B1...). The grid is the instrument; tiles inherit identity from their slot.
2. **Information density wins.** This is a workshop tool used by one person. Pack readouts, status tallies, time, loop region, fader, and buttons into the tile body. Whitespace serves rhythm, not airiness.
3. **State by glow, not by chrome.** Tally LEDs (small filled circles) communicate enabled / loaded / playing / muted at a glance. The state of the deck is readable across the whole room.
4. **Monospace everywhere.** One typeface (Martian Mono). Hierarchy via weight, size, and tracking — not by introducing a second family. The numeric readouts must align like LCD digits.
5. **The screen is recessed.** Video preview is treated as an inset screen (subtle 1px inset bevel), not a clickable thumbnail. It looks like a part of the panel that lights up.
